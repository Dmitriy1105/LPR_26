# Синтетический ML-набор для карты ЛПР: Банк «Северный контур»

## Назначение

Этот набор создан для демонстрации будущего ML-контура интерактивной карты ЛПР. **Все события, сообщения, договоры, платежи и задолженности вымышлены**. Существующие имена и personId взяты из текущего демонстрационного `src/data/crm.json`, который не менялся. Это не реальные банковские или персональные данные.

- Компания: `bank`, «Банк «Северный контур»» (стартовый клиент интерфейса).
- Контактов: 30; менеджеры: Ирина Белова, Мария Котова, Алексей Волков.
- Период: 2025-01 — 2026-11-21; дата среза: 2026-11-21.
- Валюта: RUB; даты: YYYY-MM-DD.
- Источник: `src/data/crm.json`.
- Генератор: `scripts/generate_synthetic_bank_data.mjs` (фиксированный seed `20261121`).
- Результат: `src/data/synthetic/bank_ml_v1.json`.

## Связи

`personId` ссылается на существующий контакт `bank-p0 ... bank-p29`. Договор содержит ссылки на подписанта, закупки, финансы, ответственного менеджера и сделку. Счета ссылаются на договор; платежи — на счёт и договор; задолженность рассчитывается как сумма счёта минус платежи по нему на дату среза. `evidenceIds` ручной оценки ссылается только на коммуникации, произошедшие не позднее даты оценки.

Все e-mail адреса используют зарезервированный домен `.example`. Записи звонков — **только синтетические текстовые диалоги**, аудиофайлов нет. Имена, суммы, даты и тексты не отражают реальные отношения.

## Предлагаемые ML-задачи

1. NLP извлечение фактов из писем, звонков и протоколов: темы, роли, поддержка/возражения, обязательства и сроки.
2. Временная оценка теплоты отношений и вероятного влияния — с объяснением на основе `evidenceIds`; исходные `manualAnnotations` — субъективные учебные метки, не достоверная истина.
3. Сигналы рисков: пропущенные контакты, концентрация взаимодействий, просрочка счетов и изменение условий договора.
4. Рекомендации следующего контакта и маршрута согласования с учётом дат и роли, с обязательным подтверждением менеджером.

**Методологическое ограничение:** один вымышленный клиент и шаблонные тексты не подходят для доказательства качества ML-модели. Набор годится для тестирования схемы, ETL, интерфейса, связей, прототипа NLP и демонстрации. Для обучения обобщающей модели потребуются разнообразные сценарии, независимые тестовые компании и экспертная разметка. Не допускать утечки будущих платежей, договоров и ручных оценок в признаки на прошлую дату.

## Воспроизведение

```bash
node scripts/generate_synthetic_bank_data.mjs
```

Файлы `src/data/crm.json` и существующие компоненты приложения при создании набора не изменяются. Данные пока **не подключены к UI и ML-модели**: это отдельный первый этап.
