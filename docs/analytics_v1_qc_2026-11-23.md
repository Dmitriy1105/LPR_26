# LPR_26 — аудит аналитики CRM и карты (2026-11-23)

## Источники
- `public/data/lpr/v1/lpr_activity_index_v1.json`: 540 синтетических CRM-активностей.
- `public/data/lpr/v1/lpr_final_payload.json`: 30 узлов, независимые коммуникационные и NLP-срезы.
- `public/data/lpr/v1/lpr_manual_assessments_v1.json`: 30 независимых синтетических ручных оценок.

## Проверки источников
- PASS: 540 уникальных ID активностей; индекс содержит 540 ссылок от контактов к активностям.
- PASS: 30 контактов графа и 30 ручных оценок.
- PASS: все ссылки активностей на контакты принадлежат реестру, все даты распознаются.
- PASS: типы: 270 email, 180 call, 90 meeting.
- PASS: диапазон исходных дат: 2025-01-16 — 2026-08-23 (+03:00).
- PASS: в последних 90 сутках относительно конца набора — 102 активности, контактов без активностей — 0.

## Существенные ограничения
1. У каждого из 30 контактов **ровно 18 активностей** за весь период. Поэтому общая интенсивность без временного фильтра одинакова у всех, и на полной выборке невозможно честно выделить слабые контакты по количеству. Не имитировать различия и не делать ложных выводов.
2. Фильтр периода отсчитывается от последней даты набора (2026-08-23), а не от сегодняшней даты. Оценка «давно не общались» является только относительной к набору.
3. Коммуникационные рёбра и NLP-свидетельства собраны из отдельного синтетического графового среза. Визуализация рёбер **не** фильтруется по дате и каналу; фильтры меняют только CRM-подсветку узлов и показатели CRM.
4. Текст NLP-свидетельства не доказывает влияние; для исторической динамики качества отношений нет подтверждённых временных оценок.
5. HHI и доли активностей считаются по назначениям активностей контактам. Для данного индекса каждая активность относится к одному контакту. В будущем при нескольких контактах на активность методику нужно уточнить.
6. Нет настоящей Bitrix24 интеграции, исторических менеджерских оценок, внешних организационных данных и подтверждения рекомендаций.

## Изменения
- `public/lpr-workbench.html`: три режима подсветки (оценка, интенсивность CRM, отсутствие активности), окно 90/180/365 дней или весь период, фильтр каналов, текстовые пояснения и переход к аналитике.
- `public/lpr-analytics.html`: шесть объяснимых модулей; показываются только метрики, поддержанные источниками.
- `public/lpr-contact.html`: переход в аналитику выбранного контакта.

## Статус тестирования
Проверка контрактов и распределений выполнена по GitHub JSON. Автоматический браузерный E2E и `npm run build` **не выполнялись**. Требуется проверить SVG, выбор узлов, фильтры, пустые состояния и адаптивность на опубликованном GitHub Pages. Отдельная статическая HTML-страница не изменяет React-сборку.
