# Учебный набор REST-подобных данных Битрикс24

Все файлы набора остаются в `src/data/bitrix24_contract_v1/`. Это **синтетические данные**, а не выгрузка реального портала.

## Состав и методы

- `companies/`, `contacts/`, `deals/`, `invoices/`: `crm.item.list` (`result.items`, `entityTypeId` 4, 3, 2, 31).
- `activities/`: `crm.activity.list` (`result`, `TYPE_ID` 2 — звонок, 4 — письмо, 1 — встреча).
- `tasks/`: `tasks.task.list` (`result.tasks`).
- `nlp/call_transcript_responses.json`: примеры ответов `crm.activity.call.getTranscript`.
- `nlp/email_content_responses.json`: **синтетический адаптер**, не официальный REST-метод. Канонический текст письма хранится в `activities/*/DESCRIPTION`.
- `nlp/missing_text_scenarios.json`: варианты отсутствующих расшифровок, отказа в доступе и пустых текстов для тестов. Они не подменяют основной набор.

## Воспроизводимость

В каталоге `enrichment/` находятся **исходные авторские синтетические тексты и метаданные**, которые генератор накладывает на базовые записи. Повторная генерация не должна уничтожать расширенные письма, встречи и расшифровки.

```bash
node scripts/generate_bitrix24_contract_fixtures.mjs
node scripts/generate_bitrix24_nlp_corpus.mjs
npm test
npm run build
```

Генератор NLP-корпуса создаёт производный файл `src/data/synthetic/bank_nlp_corpus_v1.json`, но **не переписывает** канонические REST-подобные ответы.

## Граница между источниками

`src/integrations/bitrix24/extractRestNlpDocuments.mjs` извлекает текст из `activities/` и `nlp/call_transcript_responses.json` без использования заранее рассчитанных NLP-оценок. При отсутствии текста возвращается `status: "missing_text"`, а не придуманная расшифровка.

**Важно:** действующий UI карты (`src/api/crmApi.ts`) по умолчанию продолжает читать `src/data/crm.json`. REST-фикстуры пока не подключены как источник данных непосредственно к визуальной карте. Это отдельный шаг интеграции; не следует утверждать, что интерфейс уже работает на REST-данных. Ручные аналитические оценки в REST JSON не включены.

## Ограничения

Учебная имитация не воспроизводит авторизацию, полноценный сервер, все REST-методы и все возможные версии Битрикс24. Для отдельных сущностей применяется `crm.item.list`, для активностей — более старый `crm.activity.list`. Варианты пустых текстов представлены отдельно, чтобы основной демонстрационный набор оставался полным.
